# Day 2: Conditional Statements and Loops in C

This folder contains C programs focused on decision-making (`if`, `else if`, `else`) and iterative control structures (`for`, `while`).

## 📂 Programs Included

### 🔹 Conditional Statements
* **`Two numbers equal or not.c`** – Checks whether two given integers are equal or not.
* **`Positive or Negative.c`** – Determines if a number is positive, negative, or zero.
* **`Odd Even.c`** – Checks whether a given number is odd or even using the modulus (`%`) operator.
* **`Greatest of 2 numbers.c`** – Compares two numbers and prints the larger one.
* **`Greatest of 3 numbers.c`** – Finds the largest among three given numbers using nested or ladder `if-else` statements.
* **`Leap Year.c`** – Checks whether a given year is a leap year based on divisibility rules.
