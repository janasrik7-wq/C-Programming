# Day 1: C Programming Basics

Welcome to *Day 1* of my C Programming repository! This folder contains foundational programs covering basic syntax, standard input/output (printf and scanf), data types, escape sequences, and simple arithmetic operations in C.

## 📂 Programs Included

| File Name | Description | Key Concepts |
| :--- | :--- | :--- |
| *Slow and 'steady' wins the race.c* | It prints the output single quotes around 'steady'. | Added single quotes/ escape sequences(\') |
| *To print integer.c* | Reads and displays an integer value. | int, %d format specifier |
| *float.c* | Demonstrates working with floating-point numbers. | float, %f format specifier |
| *Character .c* | Handles single character input and output. | char, %c format specifier |
| *Sum of two integers.c* | Takes two integers as input and prints their sum. | scanf(), Arithmetic operators (+) |
| *To print backslash.c* | Demonstrates how to display a backslash (\) in output. | Escape sequences (\\) |
| *Printing percentage symbols.c* | Shows how to print a literal percentage sign (%). | Format specifiers (%%) |
